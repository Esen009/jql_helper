# JQL Helper

A single-page tool that builds Jira JQL queries from dropdowns, so you don't have to remember the syntax.

Pick your filters — project, issue type, status, priority, assignee, date range, and sort order — and the query assembles itself instantly. From there you can copy it to the clipboard or open Jira's issue search directly with the query pre-filled.

Queries you use often can be saved by name. Three examples are included to get you started. Saved queries and your Jira address are stored in the browser and survive a page refresh.

## How to open it

Double-click `index.html`. It opens in your default browser and works immediately — there is no server, no install, and no internet connection required.
